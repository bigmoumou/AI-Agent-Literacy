WEEK 01

為什麼要學 AI Agent Literacy

AI 已經不只會聊天：它會自己打開資料夾、讀檔、寫檔、跑指令。這門課要練的，是帶 AI 做事的素養（AI Agent Literacy）：你給方向、設界線、驗收，AI 動手做。這週先講為什麼要學，再看這門課怎麼上。目標只有一個：成為一位厲害的 AI 駕駛員。

影片 01AI 會自己動手做事了，我們要學什麼？AI Agent Literacy

  1. AI 從聊天走到做事。同一件事（把筆記整理成一份報告）：網頁版 AI 聊天看不到你的檔案，要你一段一段貼給它，答案出來了，複製、貼上、存檔還是你自己來；AI Agent（例如 Codex）交代一句話就好，它自己打開資料夾、讀檔、寫出 report.md，做完還會自己檢查一遍。差別在哪裡：網頁版 AI 聊天在網站上（雲端），看不到你電腦裡的檔案，只看得到你貼給它的；本地端的 AI Agent 就在你的電腦上做事，能打開資料夾、讀檔、寫檔、執行指令。它能動你的電腦，所以要學會帶它。

  2. AI Agent 素養（AI Agent Literacy）。不是要你會寫程式，而是會帶 AI 做事：給方向、設界線、驗收。AI Agent 會做的事越來越多，這三件事就是這門課一直要練的。

  3. 你是 AI 駕駛員。沒給方向，AI 也會開到目的地：它很聰明，走錯了就退回來再換一條。只是一路試錯、繞了很多路，花的時間更久，試錯的痕跡也會留在專案裡：程式碼品質變差，以後更難管理、維護。所以要給方向（要做什麼、做到什麼程度）、設界線（哪些不能碰、不能做）、驗收（到了，自己檢查一遍），少走冤枉路。

  4. 交出去的東西，你負責。AI 寫的報告，交出去之前先問自己兩件事：我看得懂嗎？我檢查過嗎？看得懂、檢查過，才交出去。就算 AI 以後什麼都做得到，還是要有人負責：這就是管理者、駕駛員的價值。

影片 02這門課要怎麼上，才學得最好？工具、實作、自學

  1. 工具：兩個就夠。Codex 桌面版讓 AI 動手做；VS Code 讓你看、改 AI 寫的檔案。兩個看的是同一個資料夾。建議自費買 AI，上課效果會更好：ChatGPT（Codex）或 Claude 都可以。還沒付費，可以先試 Codex Free Plan：目前的用量，夠輕量的上課使用。

  2. 從 CLI 到桌面版。工程師過去習慣用 CLI（Command Line Interface，指令列介面），在終端機裡打字下指令，例如 Codex CLI、Claude Code。到 2026 年 10 月，桌面版（Codex、Claude 桌面版）的功能已經能取代 CLI，而且對新手友善：拖資料夾進去就是專案、看得到改了哪裡、有內建瀏覽器。這門課用桌面版。

  3. 很多實作，評分看過程。每週都有動手做的任務。評分不只看成品，也看過程：你寫的 BRIEF.md、VERIFY.md 和 git 紀錄。你自己想的部分最重要；交出去的東西，你負責。

  4. 卡住了，照這三步來。AI 時代更注重自學：① 先自己試；② 問 Codex，把錯誤訊息貼給它：「這個錯誤是什麼意思？怎麼修？」；③ 回看影片章節：點影片下面的片段，直接跳到那一段。

  5. 用母語就好。用你最熟的語言跟 AI 說話：繁體中文、简体中文、English、Tiếng Việt 都可以。這是 AI 時代的優勢：不用先過語言這一關，進入的門檻一下子就低了。我們要學的，是使用新工具的素養；掌握用法之後，發揮想像力更重要。

  6. 一週一站，作品放進作品集。課程地圖上一週一站，Week 1 到 16，每一站都要動手做，後面的週次陸續開放。同學做的作業網頁，會放在網站的作品集，學號會遮住。
