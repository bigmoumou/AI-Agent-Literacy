# 學習分析概論（虛構課程）評分說明

這份說明和 `grades.csv` 是同一門課的資料。成績表是助教從兩個班的登錄表合併的。**表裡的姓名、學號都是虛構的。**

## 學期成績怎麼算

| 項目 | 比重 |
|---|---|
| 作業（作業1～作業4 的平均） | 30% |
| 小考（小考1、小考2 的平均） | 20% |
| 期中考 | 20% |
| 期末考 | 30% |

- 學期成績四捨五入到整數，**60 分（含）以上及格**。

## 考試沒有分數的時候

- 考試欄寫「缺考」：沒有請假就沒來考，**這次考試算 0 分**。
- 考試欄空白、備註寫「請假」：請假有核准，**這次考試不算**。學期成績用其他項目按比例換算。
  例如期末考請假：用作業 30%、小考 20%、期中考 20%（共 70%）算出來，再換算成 100 分制。

## 補交

- 有同學補交作業後，助教重新登錄了一次。同一位同學如果出現兩列，**以「登錄時間」比較晚的那一列為準**。

## 個人資料

- 成績是個人資料。**公開的報告**（包括放在 GitHub 上的）**不可以出現學生姓名**；要指出某位同學時，用**學號末三碼**。
