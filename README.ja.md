国立台湾師範大学（NTNU）の授業「学習分析ツール」（Learning Analytics Tools）のコースサイトです。毎週いくつかの短い動画に、チャプターと要点を添えて公開しており、学生は授業のあと自分のペースで復習できます。授業担当の教員が内容を企画し、すべての動画をレビューしています。サイトと動画の開発は Codex と Claude が協力して行い、完成した動画は両者が互いにレビューしています。

## サイトの内容

- **毎週の動画**：Week 3 から、毎週いくつかの短い動画（課題の説明と補足教材を含む）を公開しています。1 本 1〜5 分で、ナレーションはなく、アニメーションとテロップで説明します。動画内の文字は繁体字中国語です。サイトの表示言語は繁体字中国語・簡体字中国語・英語・ベトナム語に対応しています（日本語はまだありません）。
- **シナリオ型の試験（Week 6）**：トップページの「TEST」から入ります。リモートのコンピューター（Mac または Windows）に接続し、ヒントなしで課題をひとつずつクリアしていきます。
- **仮想リモート練習**：ブラウザ上で動く Mac／Windows のシミュレーター。毎週同じコンピューターで、その週の課題に取り組みます。壊してしまっても、やり直せば大丈夫です。
- **作品集**：公開に同意した学生の課題ページ。
- ログインも cookie も不要で、視聴の進み具合は自分のブラウザにだけ保存されます。アクセス数は Cloudflare Web Analytics でページごとに数えるだけで、個人は特定しません。ライト／ダークモードに対応しています。

## 作り方

- **役割分担**：教員が教材を用意して方向を決め、毎回レビューします。サイトと動画の開発は Codex と Claude が協力して行います。
- **映像も音もコードで作成**：すべてのフレームは HTML・CSS・JavaScript で書いた Web ページで、1 フレームずつレンダリングして動画にしています（HyperFrames、GSAP、Playwright、FFmpeg を使用）。制作フローは主に opus-video skill を参考にし、授業に合わせて独自に手を加えています。BGM と効果音もコードで合成しています。動画生成モデルは使っていません。
- **相互レビュー**：完成した動画は Codex と Claude が互いに、流れ・説明のわかりやすさ・画面の細部をレビューし、最後に教員が確認してから公開します。
- **配信**：Cloudflare Pages 上の静的サイトで、動画は別の Cloudflare メディアサイトから HLS（hls.js）で配信しています。

詳しい制作フローは [docs/about.md](docs/about.md)（繁体字中国語・英語）にあります。

## 自分の授業で使う

サイトは素の HTML・CSS・JavaScript で、ビルドは不要です。そのまま fork できます。

```bash
git clone https://github.com/bigmoumou/Learning-Analytics-Tools.git
cd Learning-Analytics-Tools
python -m http.server 8000
```

動画のストリーミングファイルはこのリポジトリではなく、別の Cloudflare プロジェクト（メディアサイト）に置いてあるため、fork したサイトでも動画はこの授業のメディアサイトから再生されます。自分の動画に差し替えるときは `assets/video.js` の `MEDIA` を変更してください。ほかに変更が必要な箇所は [docs/維護說明.md](docs/維護說明.md)（繁体字中国語）にあります。
