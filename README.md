Course site for **Learning Analytics Tools** at National Taiwan Normal University (NTNU): a few short videos each week, with chapters and key points, for students to review at their own pace. The teacher plans the content and reviews every video. The site and the videos are developed by Codex and Claude working together, and each finished video is reviewed by both of them.

## What's on the site

- **Weekly videos**: from Week 3 on, a few short videos a week, including homework walkthroughs and extras. Each runs 1–5 minutes with animation and title cards, no narration. The text inside the videos is Traditional Chinese; titles, chapters and key points are translated.
- **Scenario-based exam (Week 6)**: the "TEST" entrance on the homepage. You connect to a remote computer (Mac or Windows) and complete the tasks one level at a time, with no hints.
- **Virtual remote practice**: a simulated Mac or Windows PC in the browser. Every week uses the same computer with that week's missions; break something and just start again.
- **Showcase**: student homework pages shared with their permission.
- No login and no cookies; watch progress stays in your own browser. Page views are counted with Cloudflare Web Analytics, without identifying anyone. The interface is available in Traditional Chinese, Simplified Chinese, English and Vietnamese, in light or dark mode.

## How it's made

- **Roles**: the teacher supplies the material, sets the direction and reviews every round. The site and the videos are developed by Codex and Claude together.
- **Video made from code**: every frame is an HTML, CSS and JavaScript page rendered to video (HTML-to-video), with HyperFrames, GSAP, Playwright and FFmpeg. The workflow mainly draws on the opus-video skill, with our own changes for this course. Music and sound effects are synthesized in code too. No video-generation model is used.
- **Cross-review**: Codex and Claude review each other's videos for flow, clear teaching and visual detail, and the teacher gives the final approval.
- **Delivery**: a plain static site on Cloudflare Pages; the videos stream as HLS (hls.js) from a separate Cloudflare media site.

The full workflow and lessons learned are in [docs/about.md](docs/about.md) (Traditional Chinese and English).

## Use it for your course

The site is plain HTML, CSS and JavaScript with no build step, so you can fork it:

```bash
git clone https://github.com/bigmoumou/Learning-Analytics-Tools.git
cd Learning-Analytics-Tools
python -m http.server 8000
```

The video streams are not in this repository but on a separate Cloudflare project (the media site), so a fork plays them from this course's media site. To use your own videos, change `MEDIA` in `assets/video.js`; see [docs/維護說明.md](docs/維護說明.md) for what else to change.
